# 第一阶段实施记录

实现分支：codex/platform-app-development。

## 已实现

- 项目归属、模板源码、带内容摘要的文件保存、Agent 写入锁、源码快照与恢复。
- 统一 Server 提供开发 API；模型请求使用当前用户保存的模型供应商配置。
- 开发 Agent 直接使用 dsh，工作目录为项目源码，会话文件单独存放；文件、Skills、终端能力已接入。
- 页面直接使用 dsh 0.2.1-alpha.1 发布的 Markdown、文件读取、终端和 diff 组件。完整 dsh Web 主界面依赖自己的 Cordis RPC 与配置服务，因此未另启 dsh Server。LocalApp 提供项目、构建、预览、发布操作。
- CLI 与 Server 共用项目检查和打包模块；构建输入使用已保存源码版本，产物摘要用于预览与发布校验。
- 每个预览独立域名、Cookie 和数据目录，一次性打开凭证；远程部署需要管理员配置 HTTPS 预览域名。
- 显式发布复用现有 installer；目标版本在 installer 的应用维护锁内检查。
- 管理员设置提供开发依赖目录、预览域名与环境检查。

## 验证结果

- CLI：35 个测试文件通过，356 项通过，1 项原有跳过。
- 项目/工作目录/构建单元测试与开发、构建 API 集成测试：5 个测试文件、9 项通过。
- Server TypeScript 检查及 Web 生产构建通过；Server 发行包脱离仓库启动与提供 Web 的测试通过。
- Shell 生命周期与编辑会话回归：2 个文件、10 项通过（包括预览加载且不接入平台在线状态）。
- 原有 dsh 能力与 Harness 回归测试：2 个测试文件、16 项通过；公共源码检查 13 项通过。
- 真实模型网页验证：创建 builtin 项目、调用当前用户模型、写入并读取 README-development.md，文件树与源码快照更新，dsh diff 可展示新增内容，重启 Server 后可恢复对话历史。
- 网页正式预览入口验证：应用模块正常加载，控制台没有 error/warn。Named SQL 的预览数据可读写，发布后的正式应用数据仍为空，隔离检查通过。
- 真实隔离构建的专用测试项目：构建成功、产物摘要、预览凭证、隔离管理 API、明确发布、重复请求及版本竞争检查通过。

## 未完成及已知限制

- 当前 macOS 的离线沙箱禁止监听本地网络端口。实际 builtin 模板的完整测试中 352 项通过，2 项 Vite 代理安全测试因 listen EPERM 超时失败。未跳过或降低这些检查，失败构建仍禁止预览和发布。
- Linux 的 bubblewrap 网络隔离路径已接入，但尚未在 Linux 执行上述完整模板验收。
- 首版仅使用管理员提前准备的模板依赖，不在构建命令中下载依赖或执行联网安装。
- 当前网页编辑和源码历史支持文本；图片等二进制源码资产、自动清理历史产物、完整资源额度、项目工具设置和剩余逐场景 E2E 尚需继续完成。
- 导入导出、多人开发、外部 Git 同步属于后续阶段，尚未实施。

不能把当前结果描述为第一阶段全部验收通过。
