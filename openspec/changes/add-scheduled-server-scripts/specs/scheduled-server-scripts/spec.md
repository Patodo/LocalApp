## ADDED Requirements

### Requirement: 由服务器运维登记脚本

统一 Server SHALL 仅从运维指定的本地配置读取任务，并使用配置中的固定入口、参数、工作目录和环境变量名单。配置缺省时 SHALL 禁用定时脚本能力。

#### Scenario: 缺省时禁用

- **WHEN** 运维未指定脚本配置并启动 Server
- **THEN** Server 不注册定时脚本 API 或调度器

#### Scenario: 使用固定输入执行

- **WHEN** 获授权的操作员请求执行已配置且空闲的任务
- **THEN** Server 按配置启动脚本，拒绝带执行参数的请求，并仅返回任务状态

### Requirement: 在配置窗口内自动运行

统一 Server SHALL 在监听期间根据时区与每日窗口运行任务，并跳过已占用的任务和离线期间错过的时点。调度程序 SHALL 不调用 Agent。

#### Scenario: 到达开放和关闭时点

- **WHEN** Server 运行到任务所在时区的窗口结束时点，随后运行到下一窗口起点
- **THEN** 结束时点不发起任务，起点发起任务，调度过程不请求模型

#### Scenario: 运行超时

- **WHEN** 已启动的脚本超过其时间上限
- **THEN** Server 尝试终止进程树并记录失败状态，退出后可以再次启动

### Requirement: 按任务授权用户

Server SHALL 使用有效 API Key 验证账号身份，并仅向管理员或配置中管理员所拥有的非系统组成员提供任务访问。手动触发 SHALL 额外验证任务的独立凭据。

#### Scenario: 用户权限变更

- **WHEN** 已有任务访问权限的组成员被管理员从组里移除
- **THEN** 该用户立即无法查看或触发任务，其他用户的权限按当前成员关系计算

#### Scenario: 缺少手动触发凭据

- **WHEN** 有权访问任务的用户仅提供自己的有效 API Key
- **THEN** 可以查看已获授权的任务，但不能手动触发
